# 経緯と決定事項

claude.ai のセッション（2026年10月19〜20日）と、それを引き継いだ Claude Code での作業の記録。今のゲームの仕様は `docs/ゲーム仕様.md` にあり、ここには要望・決定とその理由を残す。あとで覆された記述には「のちに〜」と添えている。

## ユーザーの要望（時系列）

1. 謎解きゲームのシナリオ。テーマはミステリー・殺人事件。ガリレオシリーズ風だがサイエンス要素は少なめ。OSINT・デジタルフォレンジック要素、オカルト要素を少し。主人公は情報系の大学生でアングラサイト巡りが趣味。知人から家族の失踪の相談を受けて始まる
2. Webで遊べるものを。素材は仮でよい
3. 物件探しは Google Map のような地図から探す形がよい。細かい謎が雑なのでブラッシュアップ。全体の流れは良い
4. 主人公はこの事件をきっかけに「この世界」に入った。現在の主人公はベテランで、事務所の若手が昔話を語る形。主人公は今窮地にいて、続編でその話が出る
5. シナリオをもとに小説を書く
6. 登場人物のまとめと続編のあらすじ
7. 全体を見直し、設定の無理・不自然・矛盾をブラッシュアップ（人間の矛盾した行動はミスリードを誘う程度まで許容）
8. 手元の Claude Code で続けるための引き継ぎ（このフォルダ）
9. 途中まで書いた第二話の小説を見直し、続きを書く（既存部分の変更も可）
10. 第二話を第一話からの続きとして通して見直す（違和感、面白さ、不自然な点、日本語。大幅な変更も可）
11. 第二話のゲームを作る。あわせて、大きい画面でウィンドウの大きさを変えるとポインタより大きく動く不具合を直す
12. ここまで Opus 5.5 で作ってきたものを、Fable 5.2 の目で全体的に見直して改善する（2026-11-10）。目標は「ゲームとして面白く、途中で冷めない、のめりこめること」。設定・構成・謎の骨格も、良くなるなら変えてよい。ゲーム内の絵も仮置きなので本番の品質に

## 主な決定事項

- タイトル『無人放送』。毎夜3時33分から11分間、誰もいない部屋を映すアングラ配信「うつろ放送」
- 語りの形式：所員のミオが語る昔話（若い頃を振り返る形ではない）
- 第一話の犯人は久我圭吾。宮下沙耶（2021年）と水野遼（2026年）を殺害
- 第一話で唯一説明しない出来事：2026年11月の「花の配信」→ 第二話で宮下柊の仕業と判明
- 第二話『不在証明』の真犯人は榊原恒一（警視庁サイバー犯罪対策課の警部、架純の上司）
- ゲームは画面内デスクトップ型で、地図アプリ、疑似ターミナル、ハッシュ比較、差分表示、捜査ノートなどのアプリを持つ。当初は章ごとに2〜3問の小問だったが、のちに章によって1〜6問になり、答え方も「証拠をつかんで結びつける」「証拠を突きつける」が中心になった（2026-11-11）

## UI の作り直し（2026-10-20、v7）

- ユーザーの要望：「three.js などの有名 OSS でリッチな UI に」→ 相談の結果「AI っぽくない、普通のゲームの見た目ができる方法で」
- three.js は 2D 中心のゲームには合わない（使えるのは配信画面の部屋だけで、約 2.1MB と WebGL 対応の負担が大きい）ため見送り
- 形式は画面内デスクトップ型に決定（作中の端末を操作する形）。序章は 2036 年のミオの端末（明るい）、第一章以降は 2026 年の透のノートPC（暗い）
- 管理画面風の 2 列パネル・タブをやめ、タイトル画面、章扉、アイコンとウィンドウ、チャットの通知、下の語り（テキストバー）、タスクバーを作った。ライブラリは使わず自前の HTML/CSS
- 謎・正解・手がかりは変えていない。第五章に「解明」の文を追加し、エンディングは全面表示にした
- 保存データの形が変わったので保存キーを `utsuro-save-v4` に上げた（v3 の進行状況は引き継がない。のちに `utsuro-save-v5`）

## 書き方の手がかりの見直し（2026-10-20）

- ユーザーの指摘：日本語ならふつう「。」を使うので、「半角ピリオドを使っているから偽物」という手がかりは不自然。偽物が誰が見ても変な書き方だと推理にならない。逆（本人が変わった書き方をし、偽物は普通に書いている）なら自然
- 第一話の「お別れ」は普通の「。」の文章に。遼の記事はどれも「！」「？」だらけで、「お別れ」には一つもない、という気づき方に
- 透は学生のころから、日本語でも読点「，」・句点「．」で書く。2026年の架純への返信、ファイルの最後の一行、2036年のミオへのメッセージもこの書き方にした
- 第二話の自白の投稿は「全部俺がやった。」と普通の句点。透がわざと自分の癖を外した合図で、ミオだけが気づく。序章で、同じ晩のメッセージ（「．」）と投稿（「。」）の違いを読者にも見せている
- これより前の記録にある「半角ピリオド」の記述は、この見直しで置き換えた

### ゲームの形式の作り替え

弱点は「資料を読んで、ノートの入力欄や選択肢に答えを書く」問題集の形で、プレイヤーの操作が世界に触れていないことだった。謎の中身と物語の文言は変えずに、答え方と山場の体験を変えた。今の仕組みの詳細は `docs/ゲーム仕様.md`。

- ヒントを章ごとから問題ごとに変えた（詰まっている問題と関係のないヒントから順に開いていた）。開いても入力途中の答えは消えない
- 第一話・第二章の配信を、録画として再生できるようにした（20倍速、通過音で画面が揺れる、音は Web Audio の合成で初めは OFF）。左右反転ボタンで、鏡文字を自分の手で戻せる
- 操作に世界が反応するようにした。ハッシュ値が一致した瞬間、明るさを上げて人影が出た瞬間、差分を重ねた瞬間などに、透（第二話はミオ）が語りで一言反応する
- エンディングに「この話の記録」（誤答とヒントの数）を出し、タイトル画面に「解決済み」を出す
- 証拠をつかんで結びつける：選択肢の一覧から選ぶ代わりに、アプリのウィンドウの中の証拠そのもの（記事、表の行、メッセージ、カード、見取り図の印）を押してつかみ、ノートの枠にそろえて結びつける。正解だけでなく同じ種類の要素はすべてつかめる。もとの誤答の罠のうち、つかむ物に置き換えられたもの（スマホから投稿、UTC の取り違え、私の返信、一本前の列車）は残し、置き換えられないもの（「深夜に投稿」「本文が短い」「一人称が俺」など）は外した。一覧から選ぶ問題は、対決の4択も含めて 19 問から 3 問に減った
- 「あと一歩」の返事：方向は合っているが足りない組み合わせ（書き方の違いだけをつかんだ、など）は、誤答に数えずに何が足りないかを返す。最初の一問でつまずいて誤答が積み上がるのを避けるため
- 対決は証拠を突きつける形に：4択の文をやめ、その話で集めた証拠（問題を解くと手に入る）から自分で一つ選ぶ。もとの個別の言い返しは証拠ごとの言い返しとして生かし、ほかの証拠には相手の口調の決まった言い返しを 3 種類ずつ用意した。誤答は注意書きではなく相手の言い返しにした。第一話の対決 1 は、貨物の音のほかにハッシュ値の一致・ループの素材でも崩せる（どれも「配信はライブではない」を示すので、誤答にすると理不尽なため）。第二話の対決 3 で令状の映像を出したときは、誤答にせず「最後まで取っておく」と返す
- 対決で 3 回まちがえたとき：初めは対決を最初からやり直す形だったが、解いた言い分をもう一度選ぶだけの作業になり楽しくなかったので、一つ前の言い分に押し返される形にした（最初の言い分なら、そのまま）
- 対決の時間制：相手がしびれを切らすまでのゲージを出した（一つの言い分につき 90 秒。切れると 1 回まちがえた扱い）。設計では「時間で減り、正しく崩すと戻る」だったが、誤答のあとも満タンに戻すことにした（残りわずかで誤答 → すぐ時間切れ、の二重の罰を避けるため）。語りに読んでいない続きがあるあいだも止める（対決の前の場面を読んでいるうちに減るのを避けるため）が、わざと読み終えずに考える抜け道をふさぐため 20 秒までにした。メニューで切れる
- 第二話 第七章に準備の場面：榊原が来るまで待つ場所を見取り図から選ぶ（カメラの真下。第一章で突き止めたカメラの位置が効く）。決めると時計が 00:10 から 03:41 まで進む。語りは小説の順（明かりを消して出る → 零時過ぎに戻る → 入口の横の壁 → 鍵の音 → スイッチ）に合わせ、もとの語りにあった「入口のすぐ下だけは映らない」は答えになるので、選んだあとに回した
- 第二話 第四章の侵入を遊べる場面に：解明の文章で語るだけだった「二度目の線」を、端末で操作する。映像を自分で開いて見て（10/11 04:21 の、男も足場もない絵を足した）、写すか写さないかを自分で選ぶ。小説ではミオは何もコピーしない。ゲームでは写しても話は同じように進むが、写しを持ったままでは切断できず、自分で消してから出る。選んだことは、第六章・第七章のミオの一言、エンディングの透との会話、記録に残る。そのため、エンディングに小説の「線を二度、越えました」のくだりを足した。コマンドは架空のもの（`connect`・`ls`・`play`・`copy`・`delete`・`wipe`・`exit`）だけで、実在の手口は書いていない
- 第二話 第六章「見逃す」を、確認の 3 問（渡すものを選ぶ／令状の期限／持ち主を来させる方法）から、「架純を動かす」場面に作り替えた（語りが答えを言っていて確認作業に近く、令状の期限は第四章と同じ答えだったため）。架純が警察官として疑問を一つずつ口にし、ミオは誰でも確かめられるもの・持ち主が差し出せるものだけで答える。問いは五つ：スマホの位置情報 → 回線の記録、取りに戻ったのでは → 柊の定点カメラ（ここで柊が名乗る）、防犯カメラに本人 → 足場の工期と投稿（予定表は解いたあとの語りで見せる）、元の映像は残っているか → マンションの案内（期限はミオが言う）、そして「どうして、その時刻を知ってるの」。最後の問いだけは、証拠の一覧の最後にある「何も出さない」を選ぶのが正解で、ミオが黙ると架純が「聞かないでおく」と言う。そのあと、いまの「持ち主を来させる方法」につなぐ
  - 対決と違い、ゲージも 3 回での押し返しもない。「何も出さない」はどの問いでも選べ、出すものがある問いでは架純が「黙っていられたら、私は動けない」と返す（誤答に数えない）。そのため、最後の問いで初めて現れる選択肢にはならず、正解だと見え見えにもならない
