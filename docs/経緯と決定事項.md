# 経緯と決定事項

claude.ai のセッション（2026年10月19〜20日）と、それを引き継いだ Claude Code での作業の記録。

## ユーザーの要望（時系列）

1. 謎解きゲームのシナリオ。テーマはミステリー・殺人事件。ガリレオシリーズ風だがサイエンス要素は少なめ。OSINT・デジタルフォレンジック要素、オカルト要素を少し。主人公は情報系の大学生でアングラサイト巡りが趣味。知人から家族の失踪の相談を受けて始まる
2. Webで遊べるものを。素材は仮でよい
3. 物件探しは Google Map のような地図から探す形がよい。細かい謎が雑なのでブラッシュアップ。全体の流れは良い
4. 主人公はこの事件をきっかけに「この世界」に入った。現在の主人公はベテランで、事務所の若手が昔話を語る形。主人公は今窮地にいて、続編でその話が出る
5. シナリオをもとに小説を書く
6. 登場人物のまとめと続編のあらすじ
7. 全体を見直し、設定の無理・不自然・矛盾をブラッシュアップ（人間の矛盾した行動はミスリードを誘う程度まで許容）
8. 手元の Claude Code で続けるための引き継ぎ（このフォルダ）

## 主な決定事項

- タイトル『無人放送』。毎夜3時33分から11分間、誰もいない部屋を映すアングラ配信「うつろ放送」
- 語りの形式：所員のミオが語る昔話（若い頃を振り返る形ではない）
- 第一話の犯人は久我圭吾。宮下沙耶（2021年）と水野遼（2026年）を殺害
- 第一話で唯一説明しない出来事：2026年11月の「花の配信」→ 第二話で宮下柊の仕業と判明
- 第二話『不在証明』の真犯人は榊原恒一（警視庁サイバー犯罪対策課の警部、架純の上司）
- ゲームは章ごとに2〜3問の小問。地図アプリ、疑似ターミナル、ハッシュ比較、差分表示、捜査ノートを持つ

## UI の作り直し（2026-10-20、v7）

- ユーザーの要望：「three.js などの有名 OSS でリッチな UI に」→ 相談の結果「AI っぽくない、普通のゲームの見た目ができる方法で」
- three.js は 2D 中心のゲームには合わない（使えるのは配信画面の部屋だけで、約 2.1MB と WebGL 対応の負担が大きい）ため見送り
- 形式は画面内デスクトップ型に決定（作中の端末を操作する形）。序章は 2036 年のミオの端末（明るい）、第一章以降は 2026 年の透のノートPC（暗い）
- 管理画面風の 2 列パネル・タブをやめ、タイトル画面、章扉、アイコンとウィンドウ、チャットの通知、下の語り（テキストバー）、タスクバーを作った。ライブラリは使わず自前の HTML/CSS
- 謎・正解・手がかりは変えていない。第五章に「解明」の文を追加し、エンディングは全面表示にした
- 保存データの形が変わったので保存キーを `utsuro-save-v4` に上げた（v3 の進行状況は引き継がない）

## 人物関係と第二話の組み直し（2026-10-20）

- ユーザーの指摘：ミオと透の関係をもっと物語に合うものにしたい。第二話が第一話の焼き直しに見える
- ミオは篠宮リサーチの所員。2032年、17歳で企業のサーバーに侵入し内部資料を公開する告発アカウントを運営していたところを透に突き止められ、通報されずに事務所へ拾われた元ハッカー。透への気持ちは憧れと恩返し
- ミオの性別は明言しない（ユーザーの指定）
- 恋愛要素は控えめ。透と架純は十年間言葉にしないまま想い合っている。ミオと架純は恋愛としては描かず、読者がそう受け取れるかもしれない程度の余白だけ残す（ユーザーの指定）
- 第二話は第一話の手がかりを再利用しない形に組み直した。半角ピリオドは犯人の偽装ではなく、透が自分で書いた合図（意味を裏返す）。明るさ補正と電源ノイズは使わず、防犯カメラの日付は工事の足場の撤去日から割り出す。ミオは違法な侵入でしか証拠に届かない葛藤を抱え、架純はそれを見逃す選択をする。柊はミオのハッカー時代の知り合い（holly）
- 第一話の序章に、ミオの過去をほのめかす一文を追加（「四年前、私は透さんに見つけられた側の人間だった」）

## ローカル配信と公開の準備（2026-10-20）

- このリポジトリを正とし、ゲームは GitHub Pages で公開、ドキュメントもすべてここに置く方針に（claude.ai 上の元データへのリンクは削除）
- ローカルでは `docker compose up` で nginx（digest 固定、非 root・読み取り専用、127.0.0.1 のみ）が `game/` を配信する
- 公開は GitHub Actions。テストが通ったら `game/` をそのまま Pages に上げる。Action はコミット SHA で固定し、`pages: write` は deploy ジョブだけ
- CSP は Pages でも効くよう `index.html` の meta に移した
- README を追加。あらすじはネタバレなし。ほぼすべて AI（Claude Opus 5.5）製であることを明記

## プレイヤー視点での改善（2026-10-20）

- 第五章の後半を、久我との対決に作り替えた。言い分（配信はありのまま／うちとは無関係／自分で書いて出ていった／映ったのは霊）に証拠を突きつけて崩し、最後に開けさせる場所（押入れ）を入力する。エンディング冒頭の謎解きのおさらいは削った
- 総当たりで解ける選択式（貨物線、遼の居場所、犯人）を記述式に。選択式はラジオボタンの一覧にして、長い選択肢も全文読めるように
- チャットは自動で開かず、通知と未読の印で知らせ、入力中の表示をはさんで一通ずつ届く
- 端末のコマンド履歴（↑↓）、10/11 の録画の拡大、正解時の演出、次の問題への自動スクロールを追加
- 看板・建物名の答えで、中黒やひらがな・カタカナの混在を受け付けるように
- エンディングに、ミオが「全部俺がやった.」の半角ピリオドに気づく場面を追加（小説と揃えた）
- 第三章の語りで透が操作説明をしていたのを、ゲームの案内に変更

## 小説の読みやすさの改善（2026-10-20）

- 謎解きの場面で表とコマンド出力が続き、読む速度が落ちていたのを整理。表（操作履歴、位置共有、貨物時刻表、建物の一覧、ハッシュ値14行）はすべて地の文にし、コマンド出力は核心だけ残した（6か所 → 2か所）
- 推理の「気づく瞬間」（UTC の取り違え、鏡文字、日曜の貨物の音、ハッシュ値の一致、継ぎ目の襖）は残した。ハッシュ値は一致した2行だけを見せる形に
- 終章に「四年前、透さんが私にたどり着いたのも、ログに残った私の小さな癖からだった」を追加（第二話への種）
