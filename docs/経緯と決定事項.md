# 経緯と決定事項

claude.ai のセッション（2026年10月19〜20日）と、それを引き継いだ Claude Code での作業の記録。

## ユーザーの要望（時系列）

1. 謎解きゲームのシナリオ。テーマはミステリー・殺人事件。ガリレオシリーズ風だがサイエンス要素は少なめ。OSINT・デジタルフォレンジック要素、オカルト要素を少し。主人公は情報系の大学生でアングラサイト巡りが趣味。知人から家族の失踪の相談を受けて始まる
2. Webで遊べるものを。素材は仮でよい
3. 物件探しは Google Map のような地図から探す形がよい。細かい謎が雑なのでブラッシュアップ。全体の流れは良い
4. 主人公はこの事件をきっかけに「この世界」に入った。現在の主人公はベテランで、事務所の若手が昔話を語る形。主人公は今窮地にいて、続編でその話が出る
5. シナリオをもとに小説を書く
6. 登場人物のまとめと続編のあらすじ
7. 全体を見直し、設定の無理・不自然・矛盾をブラッシュアップ（人間の矛盾した行動はミスリードを誘う程度まで許容）
8. 手元の Claude Code で続けるための引き継ぎ（このフォルダ）
9. 途中まで書いた第二話の小説を見直し、続きを書く（既存部分の変更も可）
10. 第二話を第一話からの続きとして通して見直す（違和感、面白さ、不自然な点、日本語。大幅な変更も可）
11. 第二話のゲームを作る。あわせて、大きい画面でウィンドウの大きさを変えるとポインタより大きく動く不具合を直す

## 主な決定事項

- タイトル『無人放送』。毎夜3時33分から11分間、誰もいない部屋を映すアングラ配信「うつろ放送」
- 語りの形式：所員のミオが語る昔話（若い頃を振り返る形ではない）
- 第一話の犯人は久我圭吾。宮下沙耶（2021年）と水野遼（2026年）を殺害
- 第一話で唯一説明しない出来事：2026年11月の「花の配信」→ 第二話で宮下柊の仕業と判明
- 第二話『不在証明』の真犯人は榊原恒一（警視庁サイバー犯罪対策課の警部、架純の上司）
- ゲームは章ごとに2〜3問の小問。地図アプリ、疑似ターミナル、ハッシュ比較、差分表示、捜査ノートを持つ

## UI の作り直し（2026-10-20、v7）

- 保存データの形が変わったので保存キーを `utsuro-save-v4` に上げた（v3 の進行状況は引き継がない）

## 書き方の手がかりの見直し（2026-10-20）

- ユーザーの指摘：日本語ならふつう「。」を使うので、「半角ピリオドを使っているから偽物」という手がかりは不自然。偽物が誰が見ても変な書き方だと推理にならない。逆（本人が変わった書き方をし、偽物は普通に書いている）なら自然
- 第一話の「お別れ」は普通の「。」の文章に。遼の記事はどれも「！」「？」だらけで、「お別れ」には一つもない、という気づき方に（ゲームの選択肢も「「！」や「？」がひとつもない」に）
- 透は学生のころから、日本語でも読点「，」・句点「．」で書く。2026年の架純への返信、ファイルの最後の一行、2036年のミオへのメッセージもこの書き方にした
- 第二話の自白の投稿は「全部俺がやった。」と普通の句点。透がわざと自分の癖を外した合図で、ミオだけが気づく。序章で、同じ晩のメッセージ（「．」）と投稿（「。」）の違いを読者にも見せている
- これより前の記録にある「半角ピリオド」の記述は、この見直しで置き換えた

遊びの形式の作り替え（2026-11-11）：

弱点は「資料を読んで、ノートの入力欄や選択肢に答えを書く」問題集の形で、プレイヤーの操作が世界に触れていないことだった。謎の中身（犯人、手がかり、正解）と物語の文言は変えずに、答え方と山場の体験を変えた。

- 証拠をつかんで結びつける：選択肢の一覧から選ぶ代わりに、アプリのウィンドウの中の証拠そのもの（記事、表の行、メッセージ、カード、見取り図の印）を押してつかみ、ノートの枠にそろえて結びつける。第一話は第一章の2問と第四章の2問、第二話は第一章のカメラの場所、第二章の投稿、第三章の終電と始発、第五章の榊原の言葉、第六章の架純に渡すもの。正解だけでなく同じ種類の要素はすべてつかめる。もとの誤答の罠のうち、つかむ物に置き換えられたもの（スマホから投稿、UTC の取り違え、私の返信、一本前の列車）は残し、置き換えられないもの（「深夜に投稿」「本文が短い」「一人称が俺」など）は外した。一覧から選ぶ問題は、対決の4択も含めて 19 問から 3 問に減った
- 「あと一歩」の返事：方向は合っているが足りない組み合わせ（書き方の違いだけをつかんだ、など）は、誤答に数えずに何が足りないかを返す。最初の一問でつまずいて誤答が積み上がるのを避けるため
- 対決は証拠を突きつける形に：4択の文をやめ、その話で集めた証拠（第一話 11 個、第二話 14 個。問題を解くと手に入る）から自分で一つ選ぶ。もとの個別の言い返しは証拠ごとの言い返しとして生かし、ほかの証拠には相手の口調の決まった言い返しを 3 種類ずつ用意した。第一話の対決 1 は、貨物の音のほかにハッシュ値の一致・ループの素材でも崩せるようにした（どれも「配信はライブではない」を示すので、誤答にすると理不尽なため）。第二話の対決 3 で令状の映像を出したときは、誤答にせず「最後まで取っておく」と返す
- 対決の時間制：相手がしびれを切らすまでのゲージを出した（一つの言い分につき 90 秒。切れると 1 回まちがえた扱い）。設計では「時間で減り、正しく崩すと戻る」だったが、誤答のあとも満タンに戻すことにした（残りわずかで誤答 → すぐ時間切れ、の二重の罰を避けるため）。語りに読んでいない続きがあるあいだも止める（対決の前の場面を読んでいるうちに減るのを避けるため）。メニューで切れる
- 第二話 第七章に準備の場面：榊原が来るまで待つ場所を見取り図から選ぶ（カメラの真下。第一章で突き止めたカメラの位置が効く）。決めると時計が 00:10 から 03:41 まで進む。語りは小説の順（明かりを消して出る → 零時過ぎに戻る → 入口の横の壁 → 鍵の音 → スイッチ）に合わせ、もとの語りにあった「入口のすぐ下だけは映らない」は答えになるので、選んだあとに回した
- 第二話 第四章の侵入を遊べる場面に：解明の文章で語るだけだった「二度目の線」を、端末で操作する。映像を自分で開いて見て（10/11 04:21 の、男も足場もない絵を足した）、写すか写さないかを自分で選ぶ。小説ではミオは何もコピーしない。ゲームでは写しても話は同じように進むが、写しを持ったままでは切断できず、自分で消してから出る。選んだことは、第六章・第七章のミオの一言、エンディングの透との会話、記録に残る。そのため、エンディングに小説の「線を二度、越えました」のくだりを足した。第四章の解明は、架純を疑う段落を最後に回した（侵入のあとに語りに流れるので、章の引きになる）
- コマンドは架空のもの（`connect`・`ls`・`play`・`copy`・`delete`・`wipe`・`exit`）だけで、実在の手口は書いていない
- 保存データの形が変わったので、保存キーを `utsuro-save-v5`・`utsuro2-save-v2` に上げた（古い進行状況は引き継がない）。時間制限の設定は `utsuro-pref-v1`
- 確かめたこと：通しプレイのテスト（新しい仕掛けの確認を足した）と、Chromium のスクリーンショット（1920×1000 と、390×800 のタッチのエミュレーション）
- 確かめていないこと：実機の iPhone でのタップ（つかむ → 下の帯 → ノートへ、の流れ）、支援技術での読み上げ、90 秒という長さが実際に遊んで妥当か
