# ゲーム仕様（game/index.html）

単一HTML・外部ライブラリなし。ブラウザで直接開けば動く。ローカルでは `docker compose up` で http://localhost:8080/ に配信できる（nginx、`tools/nginx.conf`）。公開は GitHub Pages（`.github/workflows/deploy.yml`）。第一話「無人放送」と第二話「不在証明」の二つの話を収め、タイトル画面で選ぶ。進行状況は話ごとに localStorage に保存する（第一話 `utsuro-save-v4`、第二話 `utsuro2-save-v1`）。

CSP は `index.html` 冒頭の meta で指定している。外から読むのは Google Fonts だけで、それ以外の外部通信・外部スクリプトは使えない。新しく外部のものを読むときは CSP も直す。

## 画面

画面内デスクトップ型。章ごとに「その時代の端末」のデスクトップが開き、アプリをウィンドウで開いて調べる。

- タイトル画面（`#title`、話を選ぶボタン `#start`・`#start2`）→ 章扉（`#card`）→ デスクトップ（`#screen`）。第一話は、序章が 2036 年のミオの事務所の端末（明るいテーマ `y2036`）、第一章以降が 2026 年の透のノートPC（暗いテーマ `y2026`）。第二話は、事務所の場面が `y2036`、ネットカフェ・跡地・自宅の場面がミオの古いノートPC（暗いテーマ `mio`、壁紙は足跡）
- デスクトップ: 左にアイコン（`#icons`）、ウィンドウ（`#wins`、ドラッグ・リサイズ・最小化）、下に語り（`#narr`、クリックで一行ずつ進む）、タスクバー（`#bar`、事件ファイルメニュー・開いているウィンドウ・時計）
- 小問はすべて「捜査ノート」アプリ（`data-win="note"`）で答える。答えるたびに次の問題までスクロールし、正解した問題は一瞬光る
- チャットは自動では開かない。通知（`.toast`）とアイコンの未読の印で知らせ、初めて開いたときだけ入力中の表示をはさんで一通ずつ届く（`S.seen`）。前に届いたメッセージを読み返すだけのチャット（`quiet:true`、第二話）は、通知・未読の印・入力中の表示を出さない
- 端末は ↑↓ でコマンド履歴を呼び出せる。映像（`.zoomable` の中の `.stream`）は、クリックした場所を拡大できる（第一話の 10/11 の録画、第二話の事務所の録画・定点カメラ・週刊誌の写真）
- ウィンドウの大きさは右下のつまみ（`.rz`）で変える。CSS の `resize` は、大きい画面で `zoom` をかけるとポインタより大きく動くので使わず、移動と同じくマウスの移動量を拡大率で割っている。章を切り替えたら前の章の通知は消す
- 幅 760px 以下ではアイコン・ウィンドウ・語りを縦に並べ、ウィンドウは一枚ずつ残りの高さいっぱいに開く。通知はタイトルバーの下に出し（×ボタンをふさがないため）、ウィンドウを開いたら消す。アイコンは 6 個まで一列に収め、タスクバーのボタンはアイコンだけにする。表は折り返して幅に収め（右の列の手がかりに気づけるように）、地図は縮めず横スクロールにして中央から見せる。文字の入力中は語りをしまい、入力欄から離れて 0.5 秒後に戻す（先に戻すとタップ位置がずれるため。iPhone はタップ中に仕掛けた 0.4 秒以内のタイマーで要素が現れるとクリックを取り消すため、それより長くする）
- タッチ操作（`pointer:coarse`）では、ウィンドウのボタン・端末のコマンド候補・ヒントのボタン・スライダーを大きくし、入力欄の文字を 16px にする（iPhone が入力のたびに画面を拡大しないため）。語りを続けてタップしても拡大しないよう `touch-action:manipulation` にしている
- 入力欄（解答・端末・地図の検索）は自動入力・自動修正を切っている。iPhone の Safari は `autocomplete="off"` を無視してパスワードなどを出すことがあるので、名前を `search-…` にしている（Safari は名前に search を含む欄に自動入力しない）
- 大きい画面（4K など）では、`#screen` と全面表示（`.over`）に `zoom` をかけて UI を段階的に拡大する（2400×1250 以上で 1.25 倍 … 3840×2000 以上で 2 倍）。基準はフル HD。ウィンドウのドラッグは、マウスの移動量を拡大率で割って CSS の px に直している
- スマホでの操作は、jsdom ではタップや表示を確かめられないので、Chromium のタッチのエミュレーション（CDP の `Emulation.setTouchEmulationEnabled` と `Input.dispatchTouchEvent`）で確認する
- エンディングは全面表示（`#endov`）。第一話の終わりには第二話へ進むボタン（`#toEp2`）、第二話の終わりにはタイトルに戻るボタン（`#endTitle`）がある。「最初からやり直す」は今遊んでいる話だけを消す

## 構造

- `EPS`：話ごとの設定。`key`（保存キー）, `title`, `file`（事件ファイルのメニューの見出し）, `ch`（章データ `CH1` / `CH2`）, `ending`（終章の HTML を返す関数 `ending1` / `ending2`）, `term`（端末の `cmds`・`fallback`・`banner`・`chips`）。`setEp(n)` で話を切り替えると、`CH`・`S`・`KEY` がその話を指し、端末・地図・ハッシュ比較の一時的な状態は消える
- `CH1` / `CH2` 配列：章データ。各章は `id`, `no`, `title`, `theme`, `mark`（壁紙の右下の透かし文字。2026年の章は壁紙の中に ghostwire の文字があるので空）, `clock`（作中の日時）, `where`, `narr`（語り）, `chat`（チャットアプリの会話。`me` の名前は 2026 年の章なら透、それ以外はミオ）, `open`（章の始めに開くアプリ）, `steps`, `hints`, `solved`, `apps`。省略できるものに `next`（解明のあとのボタンの文字）, `boot`（前の章から続けて開いたとき章扉に出す起動の表示）
- `narr` の各行は `[話し手, 本文, 'frame']`。`'frame'` は 2036 年のミオの一言（青で表示）。章を解くと `solved` の段落も語りに流れる
- `apps` の各要素は `{id, name, icon, title, w, h, flush, html, init}`。`init` はウィンドウを開いた直後に呼ぶ（地図・端末・ハッシュ比較・差分・明るさ補正・映像の拡大 `initZoom`・回線の記録 `initNet`・Web 検索 `initSearch`）
- `steps` の種類
  - `text`：自由入力。`check(v)` で判定（入力は NFKC 正規化・空白除去・小文字化済み）。`traps` は [正規表現, 誤答時のメッセージ]
  - `choice`：単一選択（ラジオボタンの一覧。選択肢は長くても全文読める）。`answer` は選択肢のインデックス。`why(i)` が誤答メッセージ
  - 総当たりで解けないよう、答えを一つに絞れる問題はなるべく `text` にする
  - `tag` を付けると「Q5-1」の代わりにその見出しを出す（第五章の「対決 1」など。「対決」で始まると回答ボタンが「突きつける」になる）
  - `multi`：複数選択。`answer` はインデックス配列。`why(sel)`
  - 各 step の `memo` は捜査ノートの「わかったこと」に追記される
- アプリの特殊UI
  - `#mapapp`：地図（`PLACES` 配列、`mapSVG`、`placeCard`）
  - `#tout`：疑似ターミナル（`TERM` オブジェクトがコマンド → 出力）
  - `#htab`：ハッシュ比較（`HASH` 配列）
  - `#dbox`：差分表示（`mix-blend-mode: difference`）
  - `#br`：明るさ補正スライダー
- `roomSVG(opts)`：配信画面の部屋をSVGで描く。`dark`, `figures`, `seam`, `noflick`
- 第二話の絵とデータ：`officeSVG`（事務所のうつろ放送。`flower`・`phone`。トラックは描かない）、`planSVG`（事務所の見取り図 A〜D）、`lotSVG`（跡地の定点カメラ。`figure`・`flower`）、`photoSVG`（週刊誌の防犯カメラの写真。足場のシートに「木工務店」と電話番号の下4桁）、`netSVG` / `NETDAY`（来客用の回線の送信量。10/11 の 03:52〜03:57 と 05:14〜05:16 に山）、`SRCH`（Web 検索の結果）、`LOTLOG`（定点カメラに映った十年分の時刻）、`EVID`（手元の証拠のカード）、`TERM2`（ミオの古いノートPCの端末。`whois`・`curl`・`trace`）
- `WALL`：テーマごとの壁紙（SVG）。`y2026` は透のノートPC（配線で描いた幽霊、魚拓の年表）、`y2036` はミオの事務所の端末（首都高とビル、ネットワーク図）。読みやすさを損なわないよう薄く描く
- 終章・続編予告は `endingHTML()`

## テスト

ローカルに Node を入れず Docker Compose で実行する（Git Bash / PowerShell どちらでも可）。

```
docker compose run --rm test
```

依存（jsdom）は `package-lock.json` の integrity で検証して Docker の名前付きボリュームに入れる（`deps` サービス）。テスト本体はネットワークなし・読み取り専用・非 root で動く。

第一話を最後まで解き、タイトルに戻って第二話も最後まで解く。最後に `OK: 全章クリア` と出れば成功（終了コード 0）。どちらかの終章に届かないかスクリプトエラーが出ると `NG` で終了コード 1。誤答メッセージも途中で表示される。
