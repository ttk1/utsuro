# ゲーム仕様（game/index.html）

単一HTML・外部ライブラリなし。ブラウザで直接開けば動く。ローカルでは `docker compose up` で http://localhost:8080/ に配信できる（nginx、`tools/nginx.conf`）。公開は GitHub Pages（`.github/workflows/deploy.yml`）。進行状況は localStorage（キー `utsuro-save-v4`）。

CSP は `index.html` 冒頭の meta で指定している。外から読むのは Google Fonts だけで、それ以外の外部通信・外部スクリプトは使えない。新しく外部のものを読むときは CSP も直す。

## 画面

画面内デスクトップ型。章ごとに「その時代の端末」のデスクトップが開き、アプリをウィンドウで開いて調べる。

- タイトル画面（`#title`）→ 章扉（`#card`）→ デスクトップ（`#screen`）。序章は 2036 年のミオの端末（明るいテーマ `y2036`）、第一章以降は 2026 年の透のノートPC（暗いテーマ `y2026`）
- デスクトップ: 左にアイコン（`#icons`）、ウィンドウ（`#wins`、ドラッグ・リサイズ・最小化）、下に語り（`#narr`、クリックで一行ずつ進む）、タスクバー（`#bar`、事件ファイルメニュー・開いているウィンドウ・時計）
- 小問はすべて「捜査ノート」アプリ（`data-win="note"`）で答える。チャットの新着は通知（`.toast`）で知らせる
- 幅 760px 以下ではアイコンを上部の帯に並べ、ウィンドウは一枚ずつ全面に開く
- エンディングは全面表示（`#endov`）

## 構造

- `CH` 配列：章データ。各章は `id`, `no`, `title`, `theme`, `mark`（壁紙の右下の透かし文字。2026年の章は壁紙の中に ghostwire の文字があるので空）, `clock`（作中の日時）, `where`, `narr`（語り）, `chat`（チャットアプリの会話）, `open`（章の始めに開くアプリ）, `steps`, `hints`, `solved`, `apps`
- `narr` の各行は `[話し手, 本文, 'frame']`。`'frame'` は 2036 年のミオの一言（青で表示）。章を解くと `solved` の段落も語りに流れる
- `apps` の各要素は `{id, name, icon, title, w, h, flush, html, init}`。`init` はウィンドウを開いた直後に呼ぶ（地図・端末・ハッシュ比較・差分・明るさ補正）
- `steps` の種類
  - `text`：自由入力。`check(v)` で判定（入力は NFKC 正規化・空白除去・小文字化済み）。`traps` は [正規表現, 誤答時のメッセージ]
  - `choice`：単一選択。`answer` は選択肢のインデックス。`why(i)` が誤答メッセージ
  - `multi`：複数選択。`answer` はインデックス配列。`why(sel)`
  - 各 step の `memo` は捜査ノートの「わかったこと」に追記される
- アプリの特殊UI
  - `#mapapp`：地図（`PLACES` 配列、`mapSVG`、`placeCard`）
  - `#tout`：疑似ターミナル（`TERM` オブジェクトがコマンド → 出力）
  - `#htab`：ハッシュ比較（`HASH` 配列）
  - `#dbox`：差分表示（`mix-blend-mode: difference`）
  - `#br`：明るさ補正スライダー
- `roomSVG(opts)`：配信画面の部屋をSVGで描く。`dark`, `figures`, `seam`, `noflick`
- `WALL`：テーマごとの壁紙（SVG）。`y2026` は透のノートPC（配線で描いた幽霊、魚拓の年表）、`y2036` はミオの事務所の端末（首都高とビル、ネットワーク図）。読みやすさを損なわないよう薄く描く
- 終章・続編予告は `endingHTML()`

## テスト

ローカルに Node を入れず Docker Compose で実行する（Git Bash / PowerShell どちらでも可）。

```
docker compose run --rm test
```

依存（jsdom）は `package-lock.json` の integrity で検証して Docker の名前付きボリュームに入れる（`deps` サービス）。テスト本体はネットワークなし・読み取り専用・非 root で動く。

最後に `OK: 全章クリア` と出れば成功（終了コード 0）。終章に届かないかスクリプトエラーが出ると `NG` で終了コード 1。誤答メッセージも途中で表示される。
