# 無人放送（うつろほうそう）

毎夜三時三十三分。誰もいない部屋が、十一分だけ映る。

OSINT（公開情報の調査）とデジタルフォレンジックで怪異の正体に迫る、ミステリーの Web 謎解きゲームと小説です。登場する人物・地名・サイトはすべて架空です。

> **この作品は、ほぼすべて AI が作りました。** シナリオ、小説、登場人物の設定、ゲームのコードとデザイン、ドキュメントまで、Anthropic の Claude Opus 5.5 が作成しています。人間は方向性の指示とレビューを担当しました。

## あらすじ

2036年10月。調査会社「篠宮リサーチ」の所長・篠宮透が、殺人の容疑で逮捕された。位置情報も、防犯カメラも、本人のアカウントの投稿も、すべてが透を犯人だと言っている。透は取り調べで何も話さない。

所員の春日ミオに残されたのは、一通のメッセージだけだった。「最初の事件のファイルを読め」。

ファイルの中身は十年前、2026年の記録。情報系の大学生だった透のもとに、後輩から「兄と連絡が取れない」という相談が届く。兄が最後に追っていたのは、毎夜3時33分から11分間だけ、誰もいない部屋を映し続けるアングラ配信「うつろ放送」。部屋に人が映ったら、その人は「招かれる」という。

> ログは嘘をつかない。嘘をつくのは、ログを読む人間だ。

## ゲームの遊び方

作中の端末を操作して調べる謎解きゲームです。アプリをウィンドウで開いて証拠を集め、捜査ノートで小問に答えながら進みます。序章と全5章（試作版）。進行状況はブラウザに保存されます。

### ローカルで遊ぶ

Docker が必要です。

```sh
docker compose up
```

ブラウザで http://localhost:8080/ を開きます。止めるときは `Ctrl+C`（バックグラウンドで起動した場合は `docker compose down`）。

`game/index.html` をブラウザで直接開いても遊べます。

## ファイル構成

**`story/` と `docs/` には物語の核心や謎の答えが書かれています。遊ぶ前・読む前には開かないでください。**

| パス | 中身 |
| --- | --- |
| `game/` | Web 謎解きゲーム（単一 HTML） |
| `story/` | 小説・第一話と設定資料（ネタバレあり） |
| `docs/` | ゲーム仕様（全問の正解を含む）と制作の経緯（ネタバレあり） |
| `tools/` | 通しプレイのテストと、ローカル配信の設定 |
| `.github/workflows/` | GitHub Pages への公開 |

## 開発

ゲームを序章から終章まで自動で通しプレイするテストがあります。Node はホストに入れず Docker で動かします。

```sh
docker compose run --rm test
```

最後に `OK: 全章クリア` と出れば成功です。

## 公開（GitHub Pages）

main ブランチへ push すると、GitHub Actions（[.github/workflows/deploy.yml](.github/workflows/deploy.yml)）が通しプレイのテストを実行し、通れば `game/` を GitHub Pages に公開します。初回のみ、リポジトリの **Settings → Pages → Source を「GitHub Actions」** に設定する必要があります。
